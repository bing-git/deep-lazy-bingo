# 学习本地验证与后端接入契约

## 1. 范围

本文件对应本次教育教材、自学教材、资料采集与语音朗读的前端实现。沿用 Art Design Pro 原生布局、统一请求与授权菜单，不改变既有家庭隔离、来源许可和 AI 治理规则。显示名称调整不改变 students/adults 等路由和数据分类。

当前后端为空。浏览器可以独立验证 IndexedDB、原创材料阅读、笔记、采集任务和系统语音；真实身份、对象权限、后端定时任务和模型音频需要符合本契约的后端。
“后端部署后自动切换”指同源兼容服务上线后自动识别，不代表任意健康检查返回 200 就能替代业务接口，也不代表免登录。

## 2. 数据模式与自动切换

### 本地验证模式

- 仅在开发构建且显式 `VITE_INTERFACE_PREVIEW=true`、当前页尚未锁定后端时启用。
- IndexedDB 名称为 `dlb-learning-validation-v1`，版本 1；对象仓库为 `books`、`progress`、`sources`、`materials`、`jobs`、`speech`。
- 本地材料仅包含标明原创的体验册和用户声明有权导入的纯文本，不伪装成江苏官方教材或真实考试题库。不填写真实儿童、健康或身份数据。
- 初始化按 ID 幂等，不覆盖现有笔记或记录。存储打开失败显示真实错误，不降级成内存后声称已持久化。
- 可以导出或显式确认清空此浏览器验证库；不会修改后端数据库。清空后刷新可重新初始化原创样例。

### 能力探测

固定请求：`GET /api/v1/system/capabilities`，同源、无重定向、6 秒超时、禁用响应缓存。
该端点是公开的非敏感能力描述，不包含用户或家庭资料。与其他业务接口不同，它直接返回以下 JSON，不套业务响应信封：

```json
{
  "identity": "deep-lazy-bingo",
  "version": 1,
  "learning": {
    "library": true,
    "sources": true,
    "tts": false
  }
}
```

必须同时满足成功状态、JSON Content-Type、准确 identity/version、`library=true`，以及两个布尔功能标志。HTML、普通存活页、错误身份/版本、401、403、5xx 均不视为兼容后端。
兼容性校验不是供应链或服务端授权认证；仍依赖正确的同源部署和正常 TLS 边界。

- 页面启动、每 30 秒、窗口聚焦和网络恢复时探测，进行中的请求不重复发起。
- 一旦确认，在当前浏览器标签页的 sessionStorage 写入非敏感标记 `dlb.backend-verified.v1=1` 并重载。
- 重载后关闭本地预览，执行既有真实会话及后端授权菜单流程；没有会话时进入真实登录页。不得用本地完整目录冒充真实权限。
- 此标签页锁定后，断网、401/403 或后端故障都不会自动退回本地测试库；新标签页重新执行探测，生产构建始终不启用本地预览。
- 本地书籍、笔记、任务和语音历史**不会自动上传或混入真实数据库**。如未来需要迁移，必须另行设计有权用户确认、去重与来源校验。

后端部署至少需要能力端点、既有真实登录/用户信息/授权菜单接口，以及声明可用的学习 API；只部署能力端点会切入真实模式，但不能补出缺失业务接口。

## 3. 学习数据 API

业务前缀为 `/api/v1/learning`。现有统一客户端在 API base 为 `/api` 或 `/api/v1` 时均保持这一最终路径，拒绝页面任意指定跨源地址。
正常业务响应沿用当前客户端的 `{ "code": 200, "data": ..., "msg": "..." }` 信封；401/403 不伪装成功，失败不回退本地数据。后端必须逐对象验证会话、活动家庭、成员及可见范围。

| 方法 | 路径（省略业务前缀） | 数据 |
| --- | --- | --- |
| GET | `/books` | 当前成员有权查看的 `Book[]` |
| POST | `/books` | 导入有使用权的纯文本材料，返回 `Book`；后端重新校验字段、归属和来源 |
| POST | `/books/{bookId}/refresh` | 重新抓取选中教材并更新后端记录，返回 Book；只允许该记录对应的批准来源 |
| DELETE | `/books/{bookId}` | 从有权书架移除教材，保留应保留的历史笔记与审计；返回成功业务信封 |
| PUT | `/books/{bookId}/cover` | `{ "coverDataUrl": "data:image/..." }` 更新用户封面覆盖；空字符串表示恢复原封面，返回 Book |
| GET | `/progress` | 当前范围的 `Progress[]` |
| PUT | `/progress` | 单条 `Progress`，复合编号放在 JSON 的 id，不在 URL 中传编码斜杠 |
| GET | `/sources` | 有权管理的 `SourceSetting[]` |
| PUT | `/sources/{sourceId}` | 来源开关和周期；sourceId 为后端批准目录中的固定 ID |
| GET | `/collection-jobs` | 有权查看的 `CollectionJob[]` |
| POST | `/collection-jobs` | `{ "sourceId": "cet" }`，创建后端采集任务，不能接受任意 URL |
| GET | `/materials` | 经过授权和许可裁剪的目录元数据 `Material[]` |

当前前端使用的字段见[数据类型与本地库](../../deep-lazy-bingo-frontend/src/learning/core.ts)及[API 适配器](../../deep-lazy-bingo-frontend/src/learning/api.ts)。具体约束：

- `Book`：id、title、audience（students/adults）、stage、grade、subject、term、edition、category、units，以及 origin/source/license/updatedAt。
- 本地 Book 增加可选 `deleted`、`coverOverride`：删除通过标记从书架隐藏，初始化及重新抓取不得使其自动恢复；官方元数据更新不得覆盖用户封面和笔记。后端必须独立执行授权/保留策略，不能信任客户端标记作为权限。
- 封面覆盖只支持校验 MIME 与文件签名的 PNG/JPEG/WebP，文件不超过 2MB，预览必须成功解码且不超过 1,200 万像素。拒绝 SVG、伪装类型及任意远端图片代理；后端还需重新校验，不能依赖浏览器检查。
- `Unit`：id、title、text、meaning、extension。导入为 1–40 个单元，单元正文最多 10,000 字符，标题非空；当前导入界面采用单段纯文本。
- category 为 `课程`、`CET4`、`CET6`、`IELTS` 或 `拓展`。界面按阶段、年级、学科、学期、教材版本筛选学生书架，成人按英语类别筛选。
- `Progress`：id（书籍/单元组合）、read、favorite、note（最多 4,000 字符）、updatedAt。该 id 不是访问授权，后端必须从业务对象关系核验。
- `SourceSetting`：id、title、audience、enabled、hours（6/12/24）、nextRunAt、lastRunAt。
- `Material`：title、url、origin、source、license、updatedAt；仅目录标题/链接及采集时间，不宣称取得全文权利或适配所有学校当前版本。
- `CollectionJob`：id、source、status（running/success/empty/failed）、count、updatedAt、可选 error。失败与零匹配分别记录，不用样例冒充采集成功。
- `SpeechHistory`：id、kind、characters、updatedAt、status；本地不保存朗读原文、模型密钥或声音文件。

后端领域数据是事实来源；本地验证字段和客户端输入不授予家庭、成员或来源权限。未来列表规模扩大时应同步前端与服务端分页契约，不能在不改客户端的情况下悄悄把数组换成分页对象。

## 4. 受控材料采集

### 当前来源

| ID | 入口 | 采集范围 |
| --- | --- | --- |
| jiangsu | https://jyt.jiangsu.gov.cn/ | 教材/教辅/课程/教学公告的同源目录链接；公开入口不等于获取教材全文 |
| cet | https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm | 四级/六级大纲等英语目录，排除其他语种和媒体附件 |
| ielts | https://ielts.org/take-a-test/preparation-resources | 同源 IELTS 备考目录，不抓合作站点或受限正文 |

国家智慧教育 https://basic.smartedu.cn/tchMaterial 的教材正文仍使用官方外链；其公开教材目录和封面缩略图已接入，具体范围见第 7 节，不再以原创样例替代真实封面。

开发模式由 Vite 的 `POST /__learning/collect?sourceId=...` 承接固定来源读取：

- 仅回环开发服务器上的同源 POST，校验 Origin/Host，畸形或外来 Origin 安全拒绝。
- 只接收上述固定来源 ID，拒绝原型链属性和任意地址；不携用户凭据、不跟随重定向、不执行远端脚本。
- 使用成熟 HTML 解析器，只返回同源 HTTPS 链接，排除附件/音频/视频；单次 10 秒、1MB、最多 60 条，并去重。
- 当前 Node 24.14+ 可读取已配置的 HTTP(S)_PROXY/NO_PROXY；显式排除 localhost/127.0.0.1，不在浏览器、日志或文档记录代理凭据，不关闭 TLS 校验。没有相应原生能力的较老 Node 仍可运行前端，但需要另行安排受控网络出口。
- 插件仅在开发预览配置启用，不存在于生产构建的应用 API 中。真实模式使用后端任务接口，不把开发桥当正式服务。

### 定时语义与限制

本地设置及 nextRunAt 持久化，每 30 秒检查；**仅材料采集页打开时运行**，浏览器关闭、页面切到其他模块或被系统节流时不保证准点执行。恢复时每来源最多补采一次，运行中的同源任务在当前执行实例内去重。
本地定时不是跨设备/跨标签页的分布式调度保证。生产后台的持续调度、跨实例互斥、重试退避、审计和配额由后端负责，不自动迁移本地调度记录。

站点 403、网络故障、许可未明确或目录为空时保持对应状态；不绕登录、验证码、机器人限制或版权许可。江苏教材的正式版本和全文材料仍需核验或由用户提供合法可用来源。

## 5. 英文语音

### 浏览器朗读

使用 SpeechSynthesis，明确显示本地/远程系统声音，优先本地英文声音；远程声音需要用户明确同意发送当前英文。支持语速 0.5–1.5、播放/暂停/继续/停止、支持检测和卸载取消。
正文为 1–2,000 字符的英文内容；阅读到朗读的交接只存在当前内存，不进入 URL。旧播放的迟到回调不得覆盖当前播放状态。
**浏览器朗读不是模型生成，不会生成或伪造可下载的模型音频。**

### 后端模型音频

只有真实模式、`learning.tts=true` 且用户显式同意发送有权英文时启用。凭据、供应商、modelId、预算和驻留均只在后端配置；未配置时按钮禁用。

| 方法 | 路径（省略业务前缀） | 约定 |
| --- | --- | --- |
| POST | `/tts/jobs` | `{ "text": "...", "language": "en", "consent": true }`，返回 TtsJob |
| GET | `/tts/jobs/{jobId}` | 返回当前状态；客户端提供刷新任务动作 |
| DELETE | `/tts/jobs/{jobId}` | 请求取消，不能承诺已发生的模型外发/费用可逆 |
| GET | `/tts/jobs/{jobId}/audio` | 经授权的音频流，Content-Type 必须为 audio/*，客户端上限 20MB |

`TtsJob` 含 id、status（pending/running/completed/failed/cancelled）、可选 audioUrl/error。jobId 仅允许字母、数字、下划线和短横线。
完成任务的 audioUrl 必须精确为同源 `/api/v1/learning/tts/jobs/{jobId}/audio`；拒绝外域、data/javascript、路径穿越和重定向。客户端下载为受控 Blob URL 并及时回收。
后端需执行当前会话/对象授权、长度/内容校验、幂等/重复任务与额度保护、提供商超时和最小审计。前端按钮禁用与本地历史不能替代这些规则。

## 7. 真实教材目录与封面

学生书架默认展示公开目录中匹配苏教、苏科、译林及江苏凤凰出版社的版本；匹配出版社或版本不等于已确认某所学校的实际选用情况。
公开版本索引固定为 `https://s-file-1.ykt.cbern.com.cn/zxx/ndrs/resources/tch_material/version/data_version.json`，只接受其 `tch_material` 模块列出的、位于官方 s-file-1/2 主机及固定教材目录路径的最多 4 个 JSON 分片，不接受任意 URL 或重定向。

- 目录通过 `POST /__learning/textbooks` 读取，仅开发预览的回环同源请求可用。响应含 books、fetchedAt、version、officialCount、matchedCount；本次最多返回 36 本用于验证，进程内缓存 15 分钟。
- 单本重新抓取使用 `POST /__learning/textbooks?bookId={已批准教材ID}`，绕过已完成的目录缓存并只返回所选教材；找不到时真实报错，不用其他教材替代。封面地址附采集时间版本以避免旧图片缓存，不能接收任意 URL。
- JSON 读取有 25 秒超时及分片 32MB 上限，提取在线教材、真实名称、学段、年级、学科、上下册、版本、出版社和封面，不导入正文或预览页集合。
- `Book` 增加可选 coverUrl、sourceUrl、publisher。官方目录条目的 origin 为 collected，units 为空，不能拼接原创样例的章节或讲解。
- 开发端将 coverUrl 映射为 `/__learning/textbook-cover/{已核验教材ID}`，只从已取得目录对应的 r1/r2/r3 官方图片主机和 assets 路径读取 JPEG/PNG/WebP 封面。无任意 URL 参数，不带用户凭据，不跟随重定向；每图最大 2MB。
- 浏览器等比完整显示封面，缺图明确提示，不自制或冒充官方封面。只更新 books 仓库，不清空 progress、来源任务、原创书或用户材料。
- 真实模式仍使用后端 books API；后端应提供其批准的封面/官方来源字段，不能依赖仅开发存在的 `__learning` 路径。此处未部署正式教材采集或存储服务。

本次实际索引版本为 1254188463，解析出 3,263 条带封面的在线教材记录，170 条匹配江苏相关版本；页面抓取并保存 36 本，前 8 张真实封面已在浏览器成功解码。数量和版本是该次采集快照，不保证未来固定，也不代表所有条目适用于当前学校。

### 教材版本字段的含义

本地 2026-10-27 采集批次的 36 本并非统一版次：

| 教材版本标签 | 出版社 | 本批数量 |
| --- | --- | --- |
| 苏教版 | 江苏凤凰教育出版社 | 12 |
| 译林版 | 译林出版社 | 7 |
| 苏少版（五线谱） | 江苏凤凰少年儿童出版社 | 12 |
| 苏少版（简谱） | 江苏凤凰少年儿童出版社 | 5 |

- 以上 edition 是官方目录的教材版本标签，不是版权页的“第几版”。
- 本批 28 本的官方书名明确标注“根据2022年版课程标准修订”；该年份指课程标准，不等于 2022 年出版。前端仅从明确书名语句提取，不由采集日期或出版社推断。
- 另 8 本书名未标注课标修订信息，例如本批《义务教育教科书·数学五年级下册》。不能因此认定它们是旧版，也不能默认补为 2022 课标修订版。
- 出版年份、版权页版次及印次未采集核验，须查看实际教材版权页。目录采集日期 2026-10-27 和索引版本 1254188463 都不能作为教材出版版次。
- 以上为数据快照，不写死为界面规则。按最新交互要求，页面不再展示“本批教材版本说明”；版本、出版社、课标修订与未知版权页信息保留在每本教材三点菜单的“查看教材详情说明”弹窗中。

### 封面阅读与管理操作

只有封面图区域进入真实教材内容：官方教材以已校验的智慧教育详情链接打开新标签页，原创/自有材料进入本地单元阅读。书目文字与三点管理按钮不触发阅读跳转，也不复制未授权正文。
教育教材与自学教材共用书架卡片和封面比例，分别保留年级/版本或英语类别筛选。封面下方显示完整书名，空间不足时单行省略，悬停显示全名；书名右侧为无圆圈、无背景的独立三点菜单，提供重新抓取、删除、修改封面、查看教材详情说明，不嵌套在阅读链接内。删除须确认，封面编辑提供预览、错误提示和恢复原封面。没有采集来源的原创/自有材料不伪造重新抓取能力，无真实封面时明确显示占位。
