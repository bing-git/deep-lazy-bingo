## 当前状态

| --- | --- |

## 数据与事务

独立 `dlb-modules-local-v1` 含 records、meta、audit。每条记录有稳定 ID、所属模块、类型、状态、受限字段、版本与时间。记录变更和最小审计同一事务提交；输入或唯一性失败整体回滚，不留下半条状态。已有记录修改要求预期版本，不变保存不制造新审计。归档是幂等软归档。

每模块仅初始化一次稳定原创样例，时间是实际初始化时间，不伪造历史操作或监控。刷新不覆盖用户更改，不复活被归档/移除的样例。旧 learning/english/health/ai 数据库不迁移、不清空；原教材笔记经已有 API 只读展示，仍在教材页原位编辑。

学习笔记采用固定正文与来源字段：body、sourceDraftId、sourceDocumentId、bookId、unitId。共享 adoptDraft 将待审核草稿状态与稳定笔记 ID 一次事务写入；重复采纳返回同一笔记，保留其后续编辑/归档，不新增副本或审计。知识生产者与学习消费者使用相同契约。

## 非伪造边界

- 统计从实际持久记录计算；未采集的学习时长显示未知，不用随机数或假成绩充数。
- TXT 以字节、字符、许可声明及引用关系限制；分块由实际正文计算，显示半开原文区间。文档改变后旧分块不用于新检索。此处没有向量化或联网全文采集。
- 问答明确是本地关键词摘录而非模型回答；模型仍复用现有场景配置，未接后端不伪造回答。
- 服务仅保存无凭据的规范私网草稿；缺部署批准策略时访问入口关闭，不发起探测、代理、Webhook 或 DNS 验证。人工维护状态不等于实时可达性。
- 成员资料、角色和确认流程仅描述本机数据；服务端家庭隔离、真实会话及权限尚需后端。审计只记录实际本机操作的最小元数据，不编造登录事件或保存完整正文。

## 验证入口

标准 `pnpm test` 与 `scripts/learning-check.ts` 包含新增模块、跨域及路由回归。后者执行测试、类型、生产构建、限定 lint/style/format，记录真实退出码、日志与源码指纹。浏览器检查与独立命令执行分别记录，不能把同一开发者自测称为独立验收。

本轮要求与验收账来自需求 12，执行档案见 doc/analysis 下 all-modules 系列。远端模型、真实服务访问、生产认证/授权和多设备同步不在本机证据证明范围；不因页面看起来完整而宣称这些服务已上线。
