## 2. 来源与网络事实

- 主协调者实际读取了江苏省教育厅、CET 和 IELTS 官方入口。公开页面和目录链接不代表获得教材/题库全文许可；国家智慧教育教材页本次未提取有效目录，只保留外链。
- Node 直接请求三个固定来源最初均超时，证据目录 `%TEMP%/learning-evidence-yXaMZP`。
- 检查只确认系统存在 HTTPS_PROXY，没有输出其值或凭据。根据 Node 官方文档，开发连接器使用 Node 24.14+ 的 `http.setGlobalProxyFromEnv`，本机地址强制绕过代理，没有关闭 TLS 验证或新增代理依赖。
- 修订后的真实采集回执为 `%TEMP%/learning-evidence-UVKTlR/results.json`：CET 成功 6 条；江苏公开首页 403；IELTS 403；本地开发服务 HTTP 200。源抓取失败与检查脚本退出成功是不同字段，不能将后者当抓取成功。
- CET 结果只保留目录/链接，排除其他语种和媒体附件。浏览器内手动采集同样得到 success / 6，元数据留在本地库，不伪装成完整英语材料库。
- 江苏公告列表最初 403，改为已核对的公开首页读取公告链接后仍 403；没有进一步绕登录、验证码、站点或网络限制。
