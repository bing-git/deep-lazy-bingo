# 家庭服务目录需求

## 1. 范围

本模块提供已登记家庭内网服务的安全目录、直达链接和受控只读状态。它解决“找到并知道服务是否可用”，不提供任意 URL 代理、通用反向代理、服务账户密码分发、远程终端、文件操作或自动化控制。

## 2. 核心对象

| 对象       | 必需业务属性                                                   | 说明                                         |
| ---------- | -------------------------------------------------------------- | -------------------------------------------- |
| 服务目录项 | 家庭空间、名称、描述、分类、图标标识、访问地址、可见范围、状态 | 一个可被成员发现和访问的家庭服务。           |
| 访问地址   | 协议、主机、端口、路径、校验状态                               | 只保存经安全策略批准的目标，不保存访问凭据。 |
| 状态配置   | 模式、是否启用、经批准的探测目标、最后检查结果                 | P0 可仅人工维护；自动探测为后续受控能力。    |
| 状态事件   | 服务项、状态、检查时间、摘要、来源                             | 支撑异常提示和只读历史，不保存敏感响应正文。 |
| 可见范围   | 可见成员类型或明确成员集合                                     | 控制目录发现与状态可见性。                   |

## 3. 功能需求

### 3.1 服务目录管理

| ID         | 优先级 | 需求                                                                                                                               |
| ---------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| FR-SVC-001 | P0     | 家长必须能创建、查看、修改、停用和排序本家庭的服务目录项，至少填写名称、访问地址、分类和可见范围。                                 |
| FR-SVC-002 | P0     | 系统必须校验服务访问地址的协议、主机、端口和路径，并仅接受部署策略明确允许的私有网络地址或受控域名。校验失败时不得保存或访问目标。 |
| FR-SVC-003 | P0     | 服务目录项不得保存、返回或在浏览器中拼接明文用户名、密码、令牌、Cookie、授权头或其他管理凭据。                                     |
| FR-SVC-004 | P0     | 服务目录可使用受信任图标标识或用户上传的受控图片；不允许远程图标 URL 成为浏览器追踪或后端请求入口。                                |
| FR-SVC-005 | P0     | 家长必须能为服务设置可见范围。儿童默认不可见，除非家长明确启用其可见性；儿童可见项只提供安全的显示名、图标和经批准链接。           |
| FR-SVC-006 | P0     | 停用服务后，普通成员无法在目录、搜索、工作台或历史快捷入口中打开它；历史审计保留状态变化。                                         |
| FR-SVC-007 | P1     | 家长可为服务记录只读说明、使用提醒和维护窗口；说明中不得包含凭据或其他密钥。                                                       |
| FR-SVC-008 | P1     | 家长可按分类、状态和可见范围筛选目录；成员只可筛选自己有权看到的服务。                                                             |

### 3.2 链接访问与只读状态

| ID         | 优先级 | 需求                                                                                                                                         |
| ---------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-SVC-010 | P0     | 有权成员点击服务时，浏览器必须直接打开已登记地址或受控的新窗口跳转；平台后端不得转发服务页面、文件流量或认证流量。                           |
| FR-SVC-011 | P0     | 系统必须记录服务链接的配置变更与管理员操作；普通成员的链接打开事件是否记录由家庭隐私设置决定，且不得记录 URL 中的敏感查询参数。              |
| FR-SVC-012 | P0     | P0 服务状态必须支持“未知”“正常”“异常”“维护中”和“未配置”五类明确状态，并显示状态来源和最后更新时间。                                          |
| FR-SVC-013 | P0     | 状态未知、过期或未配置时，界面不得显示为正常，也不能伪造实时监控结果。                                                                       |
| FR-SVC-014 | P1     | 家长可为单个服务启用自动健康探测，但仅可从预先批准的探测类型和目标路径中选择，不能输入任意 URL、方法、请求头或请求体。                       |
| FR-SVC-015 | P1     | 自动探测必须在独立的网络策略下执行：目标地址重新解析和校验、固定超时、限制响应大小、禁止重定向、禁止凭据转发、禁止访问云元数据与非批准网段。 |
| FR-SVC-016 | P1     | 自动探测只保存规范化状态码、延迟、检查时间和脱敏摘要；不得持久化页面正文、Cookie、响应头或服务日志。                                         |
| FR-SVC-017 | P1     | 连续异常或恢复正常可生成家长站内通知；通知不应包含完整内网地址、端口、服务版本或敏感错误正文。                                               |

### 3.3 安全策略与 AI 边界

| ID         | 优先级 | 需求                                                                                                                                             |
| ---------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-SVC-020 | P0     | 服务地址验证必须拒绝未批准协议、公开互联网目标、环回地址、链路本地地址、云元数据地址和策略外网段；允许范围必须由部署配置或管理员受控白名单定义。 |
| FR-SVC-021 | P0     | DNS 名称在保存和每次后端探测前均需解析后校验实际地址；解析结果变化到不允许地址时，系统必须拒绝探测并标记配置需复核。                             |
| FR-SVC-022 | P0     | 本模块不得暴露“测试任意地址”“运行命令”“上传服务配置”“执行 Webhook”或其他会产生副作用的通用接口。                                                 |
| FR-SVC-023 | P1     | AI 仅可读取当前成员有权查看的服务名称、脱敏状态、批准的说明和状态事件摘要，用于生成只读摘要或排查建议。                                          |
| FR-SVC-024 | P1     | AI 不得执行服务请求、调用服务控制接口、触发重启/下载/删除操作，也不得根据服务说明中的文本提升自身权限或改变平台配置。                            |

## 4. 关键业务规则

- 服务地址不是通用 URL 收藏夹。所有地址都必须通过以防 SSRF 为目标的服务端策略验证；前端校验只用于改善输入体验。
- 即使服务链接在浏览器可直接访问，平台也不能假设每个成员网络可达。状态字段表示最后一次受控检查或人工维护状态，不代表用户网络连通性。
- 自动健康探测的启用权属于家长，且每项服务独立批准。关闭探测后不再发起网络请求，保留已有状态为历史信息。
- 内网地址、端口、服务版本和故障细节均可能构成敏感信息。对儿童、无权成员、通知和 AI 输入使用最小化摘要。
- 目录项删除或停用不应被用于绕过审计；可先采取软删除与保留期策略，永久清除另行定义。

## 5. 验收标准

| 编号       | 验收场景                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| AC-SVC-001 | 家长能保存一个通过策略校验的私有服务地址；提交公开地址、环回地址、云元数据地址或策略外地址时服务端拒绝保存。 |
| AC-SVC-002 | 普通成员只能看到被授权的目录项；儿童默认看不到目录，家长显式开放后也只能看到被允许的名称、图标、状态和链接。 |
| AC-SVC-003 | 点击服务链接不会使平台后端代理目标响应，也不会从 API 返回服务密码、令牌或 Cookie。                           |
| AC-SVC-004 | 未配置或检查过期的服务在目录中显示“未知/未配置”，而非“正常”。                                                |
| AC-SVC-005 | 自动探测配置只能选中预批准选项；提交任意路径、重定向、认证头或外部地址的请求被拒绝。                         |
| AC-SVC-006 | AI 服务摘要只能使用该用户可见的脱敏状态数据，无法触发服务操作或读取完整错误正文。                            |
