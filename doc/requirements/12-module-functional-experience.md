# 全模块可操作本地体验

## 本次请求

用户原文：每个模块的页面不要单纯预览，每个模块做一份最接近真实效果的页面和效果，类似教育教材。

用户不可用时授权自主决策。本轮由执行者选择 L1 本地开发与验证，不提交、不推送、不部署；不是用户手动选择的等级。实现目标是完整、本机可操作的页面，而不是把尚未实现的后端声明为真实服务。

## 基线与范围

- 当前 7 组、28 个入口，保留 Art 原生菜单、顶栏、面包屑、标签、主题和响应式布局。
- 已有教育教材、自学教材、资料采集、朗读、运动/餐食、模型配置及英语练习保留，不清空现有 IndexedDB，不回退用户改动。
- 重点替换共用“未接后端＋空表”的工作台、学习管理、知识库、学习 AI、家庭服务与家庭管理页面。
- 本机样例必须可识别且不含真实身份、儿童或健康信息。无样例与无匹配结果提供可行动空状态。示例初始化幂等，用户后续更改不得被刷新覆盖。

## 边界

- 真实会话、家庭隔离、对象授权、生产持久化和多设备同步仍依赖后端；正式模式不得无声降级到本机样例。
- AI 默认关闭，密钥不进入浏览器；现有场景配置复用。自动生成和语音模型调用没有真实后端时不可伪报成功。
- 来源导入保持小批量，不恢复动作库全量抓取。服务地址遵循既有私网白名单与凭据拒绝约束，不新增通用代理或探测器。
- 使用现有 Vue、Element Plus、idb 和测试工具，不引入第二个应用壳、装饰性营销页或未经许可资产。
