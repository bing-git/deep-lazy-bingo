# 学习与知识管理需求

## 1. 范围

本模块支持儿童课程学习与成人个人学习的完整闭环：计划、任务、内容、练习、尝试记录、学习时长、笔记和进度。它不在首期提供未经授权教材全文分发、复杂题型考试引擎或自动替代教师的评测。

## 2. 核心对象

| 对象     | 必需业务属性                                           | 说明                                         |
| -------- | ------------------------------------------------------ | -------------------------------------------- |
| 学习计划 | 所属家庭/成员、名称、目标、开始/结束日期、状态、创建人 | 为某成员定义一段时间内的学习安排。           |
| 学习任务 | 来源计划、目标成员、日期、内容或练习引用、状态         | 工作台的最小可执行学习事项。                 |
| 内容条目 | 类型、标题、正文或受控附件、标签、来源、可见范围、状态 | 类型包括知识点、讲解、笔记、阅读材料和练习。 |
| 练习题   | 内容条目、题干、题型、选项、正确答案、解释、难度、状态 | P0 仅支持单选题。                            |
| 答题尝试 | 题目、答题成员、选择、得分、反馈、提交时间             | 同一题可有不限次数的尝试，不覆盖历史。       |
| 学习会话 | 成员、开始/结束时间、时长、关联计划或内容、来源        | 记录学习时长，不替代答题尝试。               |
| 进度快照 | 成员、统计范围、完成量、正确率、时长、计算时间         | 可按需计算或缓存，但必须可从原始记录解释。   |

## 3. 功能需求

### 3.1 学习计划与任务

| ID           | 优先级 | 需求                                                                                                                   |
| ------------ | ------ | ---------------------------------------------------------------------------------------------------------------------- |
| FR-LEARN-001 | P0     | 家长必须能为本家庭儿童创建、查看、修改、暂停和结束学习计划；成人只能默认管理自己的计划。                               |
| FR-LEARN-002 | P0     | 学习计划必须至少包含目标成员、名称、目标说明、日期范围和状态；日期结束早于开始、空目标成员和无权限成员必须被拒绝。     |
| FR-LEARN-003 | P0     | 系统必须允许计划关联内容条目、练习或学习目标，并从中生成或聚合可出现在工作台的学习任务。                               |
| FR-LEARN-004 | P0     | 家长调整儿童计划的日期、内容、状态或目标后，受影响的未完成任务必须在后续工作台查询中一致更新；已完成记录保持历史关联。 |
| FR-LEARN-005 | P0     | 儿童只能查看被分配、在有效期内且处于可用状态的计划、任务和内容；不能通过 ID 枚举其他儿童或成人计划。                   |
| FR-LEARN-006 | P1     | 家长必须能按学段、年级、学科、教材版本、单元和章节组织课程目录；目录项不等于拥有或分发教材全文。                       |
| FR-LEARN-007 | P1     | 成人必须能创建英语或知识拓展学习计划，并设置主题、水平、目标词汇、阅读清单或复习目标。                                 |
| FR-LEARN-008 | P1     | 系统可支持计划模板与复制，但复制不得把原成员的学习记录、笔记、AI 草稿或私有来源自动带入新计划。                        |

### 3.2 内容、来源与笔记

| ID           | 优先级 | 需求                                                                                                                     |
| ------------ | ------ | ------------------------------------------------------------------------------------------------------------------------ |
| FR-LEARN-010 | P0     | 家长和成人必须能在授权范围内创建、查看、修改和归档知识点、讲解、个人笔记和练习内容。                                     |
| FR-LEARN-011 | P0     | 每个外部、授权或 AI 辅助内容条目必须记录来源类型、来源标题或说明、链接（如有）、版本或日期（如有）、记录时间和创建方式。 |
| FR-LEARN-012 | P0     | 内容条目必须声明可见范围。儿童只能读取明确分配给自己的内容；个人笔记默认仅创建者可见。                                   |
| FR-LEARN-013 | P0     | 归档内容不得再分配给新任务或练习，但历史学习记录必须仍能显示可理解的标题和归档状态。                                     |
| FR-LEARN-014 | P1     | 用户可上传受控学习附件；系统必须校验文件类型、大小、访问权限和下载授权，且不能把上传功能变成公开文件托管。               |
| FR-LEARN-015 | P1     | 成人可为英语内容记录词汇、短语、句子、阅读材料和复习结果；这些条目可关联计划和来源。                                     |
| FR-LEARN-016 | P2     | 系统可在来源许可和连接器验证后展示教材目录、课程标准或授权资源检索结果；无法核验的来源必须明确标注。                     |

### 3.3 单选练习与尝试历史

| ID           | 优先级 | 需求                                                                                                               |
| ------------ | ------ | ------------------------------------------------------------------------------------------------------------------ |
| FR-LEARN-020 | P0     | 系统必须支持单选题：题干、至少两个选项、唯一正确答案、可选解释、难度和状态。题目保存时必须校验选项与答案的一致性。 |
| FR-LEARN-021 | P0     | 练习必须只向有权的目标成员展示已发布题目。未提交前，客户端响应不得包含正确答案、评分依据或仅供管理者使用的解释。   |
| FR-LEARN-022 | P0     | 成员提交单选答案后，服务端必须保存一次独立答题尝试、计算结果并返回本次反馈。重复作答必须新增历史，不覆盖先前尝试。 |
| FR-LEARN-023 | P0     | 提交接口必须具备幂等保护，防止网络重试或重复点击为同一次提交创建多条尝试记录。                                     |
| FR-LEARN-024 | P0     | 反馈至少包含答题结果、正确答案、解释（如有）、提交时间和下一步操作；儿童可见反馈必须符合其内容授权范围。           |
| FR-LEARN-025 | P1     | 家长和成人必须能按成员、计划、题目和时间范围查看答题历史；儿童只能查看自己的历史。                                 |
| FR-LEARN-026 | P1     | 系统必须能把错误或低掌握度的题目聚合为错题复习视图，且保留原题来源、最后尝试和复习状态。                           |
| FR-LEARN-027 | P2     | 新题型、随机组卷、计时考试、主观题和人工批改必须单独定义评分、作弊防护、版本和兼容性规则后实现。                   |

### 3.4 学习时长、进度与分析

| ID           | 优先级 | 需求                                                                                                                            |
| ------------ | ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| FR-LEARN-030 | P0     | 成员必须能记录学习会话的开始/结束或直接填写时长，并可关联计划、内容或任务。系统必须拒绝负时长、不合理的时间顺序和无权关联对象。 |
| FR-LEARN-031 | P0     | 系统必须在学习计划、成员和家庭授权范围内汇总任务完成量、答题正确率、学习时长和最近活动，供工作台和进度页使用。                  |
| FR-LEARN-032 | P0     | 进度视图必须明确统计周期、时区、数据更新时间和计算口径；无记录时显示空状态而非零值趋势结论。                                    |
| FR-LEARN-033 | P0     | 家长可查看自己有权管理的儿童计划进度；成人默认只能查看本人进度；儿童只能查看自己的易理解进度摘要。                              |
| FR-LEARN-034 | P1     | 用户必须能按计划、时间范围、内容类型和成员（仅有权者）筛选学习记录，并在权限允许时导出。                                        |
| FR-LEARN-035 | P1     | 系统可允许更正学习会话，保留更正时间、操作者和更正摘要；不得静默篡改答题尝试的原始提交事实。                                    |

## 4. 关键业务规则

- 同一内容可被多个计划引用，但内容的归档、可见范围和来源变更应影响所有后续分配；历史记录保存当时的可理解快照。
- 计划完成和任务完成不是同义词。计划可以因日期结束、人工结束或所有任务完成而进入不同状态，界面必须明确状态原因。
- 题目内容和答案变更必须有版本策略。已产生的尝试应仍能解释当时面对的题目与答案，不能因后续编辑失去可读性。
- 学习时长是用户记录或会话计算的事实数据，不得由页面停留时间自动伪造；自动计时功能需另行定义暂停、离线和反作弊规则。
- 非授权教材、题库和扫描件不可被默认上传、抓取或公开分发。来源不明时不应在系统中标记为“官方”或“已授权”。

## 5. 验收标准

| 编号         | 验收场景                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------- |
| AC-LEARN-001 | 家长能创建儿童计划并安排一项单选练习；儿童工作台出现该任务，其他家庭成员无法读取其内容。 |
| AC-LEARN-002 | 儿童在未答题前的网络响应不含正确答案；提交后仅创建一条本次尝试并显示对应反馈。           |
| AC-LEARN-003 | 同一儿童可多次完成同一题，每次尝试分别可查；重复提交同一请求不会产生额外尝试。           |
| AC-LEARN-004 | 成人记录学习时长后，本人进度与工作台数据一致更新；家长在无授权时不看到该成人数据。       |
| AC-LEARN-005 | 内容被归档后，不能用于新建任务；已有完成记录仍保留标题、来源与归档提示。                 |
| AC-LEARN-006 | 使用无权成员 ID 创建计划、读取记录或提交答案时，服务端拒绝请求，且不泄漏目标成员信息。   |
