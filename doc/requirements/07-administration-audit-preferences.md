# 家庭管理、审计与偏好需求

## 1. 范围

本模块提供受限的家庭管理入口、授权管理、配置维护、个人界面偏好、审计查询和受控数据导出。它不把后台菜单可见性当作安全措施，也不授予管理员绕过家庭数据边界的默认权限。

## 2. 页面与对象

| 页面/对象  | 主要角色                 | 目的                                              |
| ---------- | ------------------------ | ------------------------------------------------- |
| 成员与权限 | 家长                     | 管理家庭成员档案、角色、邀请和敏感数据共享授权。  |
| 家庭设置   | 家长                     | 维护名称、时区、通知与可用功能等家庭级设置。      |
| 服务配置   | 家长                     | 维护服务目录及其状态配置，详见服务目录模块。      |
| AI 与隐私  | 家长、成人（限本人）     | 查看/管理 AI 同意、可见范围、草稿保留与可用状态。 |
| 审计记录   | 家长；系统管理员受限访问 | 查看有权范围内的安全与业务变更摘要。              |
| 个人偏好   | 全部登录成员             | 管理布局、主题、语言和表格列等非敏感设置。        |

## 3. 功能需求

### 3.1 家庭管理与高风险操作

| ID           | 优先级 | 需求                                                                                                                             |
| ------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------- |
| FR-ADMIN-001 | P0     | 只有当前家庭的家长可访问家庭管理入口及其 API；其他成员直接访问时必须被服务端拒绝。                                               |
| FR-ADMIN-002 | P0     | 家长必须能在一个页面查看本家庭成员的显示名称、成员类型、账号绑定状态、活动状态和可管理操作，不显示密码、令牌或其他成员私有内容。 |
| FR-ADMIN-003 | P0     | 家长对成员创建、停用、角色调整和儿童登录方式变更必须获得明确确认，并在成功或失败后得到可理解反馈。                               |
| FR-ADMIN-004 | P0     | 家长必须能查看、授予和撤销成人健康/AI 汇总等敏感数据共享授权；授权页面必须说明范围、受益人和撤销效果。                           |
| FR-ADMIN-005 | P0     | 家庭设置必须支持显示名称、时区和允许的基础功能开关；设置变更影响后续请求的行为，且需记录审计事件。                               |
| FR-ADMIN-006 | P1     | 家长可配置儿童是否可见特定家庭服务、哪些通知类型可产生以及 AI 功能是否可用于儿童学习草稿。                                       |
| FR-ADMIN-007 | P1     | 删除、永久清除、导出全部家庭数据、关闭家庭空间和更改所有权属于高风险操作，必须要求二次确认，并在实现前定义备份、保留和恢复规则。 |

### 3.2 个人偏好与界面设置

| ID           | 优先级 | 需求                                                                                                       |
| ------------ | ------ | ---------------------------------------------------------------------------------------------------------- |
| FR-ADMIN-010 | P0     | 登录成员必须能维护自己的侧边栏状态、专注模式、主题、语言偏好和表格列偏好；这些设置默认仅对本人有效。       |
| FR-ADMIN-011 | P0     | 个人偏好不能包含业务权限、家庭地址、凭据、健康原始数据或其他敏感业务内容。                                 |
| FR-ADMIN-012 | P0     | 用户修改偏好后，同一账号在刷新或新会话中恢复该设置；无效或过时设置必须回退到安全默认值而非导致页面不可用。 |
| FR-ADMIN-013 | P1     | 用户可重置全部或部分界面偏好，重置不影响学习、健康、家庭成员或服务配置数据。                               |
| FR-ADMIN-014 | P1     | 同一账号如可切换多个家庭，界面偏好可区分个人全局偏好和家庭上下文偏好，且切换时不泄漏前一家庭的业务信息。   |

### 3.3 审计记录

| ID           | 优先级 | 需求                                                                                                                                         |
| ------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-ADMIN-020 | P0     | 系统必须记录认证失败/成功、会话撤销、成员与角色变更、授权授予/撤销、计划关键变更、服务配置变更、AI 采纳/拒绝和数据导出等安全或业务关键事件。 |
| FR-ADMIN-021 | P0     | 审计事件至少包含事件类型、时间、操作者账号或系统主体、家庭上下文、对象类型/标识、结果和经过脱敏的变更摘要。                                  |
| FR-ADMIN-022 | P0     | 普通业务用户不能修改或删除审计事件。审计查看者只能检索自己有权了解的家庭和对象范围。                                                         |
| FR-ADMIN-023 | P0     | 审计详情不得存储密码、会话令牌、API 密钥、完整敏感文本、完整健康内容或服务响应正文。                                                         |
| FR-ADMIN-024 | P1     | 有权家长必须能按时间、操作者、事件类型和对象类别筛选审计记录，并导出脱敏范围内的结果。                                                       |
| FR-ADMIN-025 | P1     | 系统必须定义审计保留期限、完整性保护方式与归档策略；期满删除或归档动作本身也必须留存最小事件摘要。                                           |

### 3.4 数据查看与导出

| ID           | 优先级 | 需求                                                                                                                         |
| ------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| FR-ADMIN-030 | P1     | 成员必须能导出自己有权读取的学习、健康或个人设置数据；导出内容、范围、格式和生成时间必须可见。                               |
| FR-ADMIN-031 | P1     | 家长导出儿童学习数据时，只能包含本家庭、被管理儿童和有权学习范围内的字段；成人健康数据除非有单独授权，否则不得纳入家庭导出。 |
| FR-ADMIN-032 | P1     | 导出必须通过受控异步任务或受限下载链接完成，并设置访问检查、过期时间、下载审计和合理的数据量限制。                           |
| FR-ADMIN-033 | P2     | 用户的数据更正、删除和可携带性请求必须在明确的数据保留、备份和法定义务规则后实现；不能以简单数据库删除替代完整流程。         |

## 4. 关键业务规则

- 管理页面可以根据权限隐藏入口，但真正的授权始终由后端进行；任何按钮、批量操作、导出与下载都必须单独检查权限。
- 审计记录解释“发生了什么”，而不是保存所有原始业务内容。变更摘要应足以支持排查，但避免二次扩大敏感数据访问。
- 家庭时区变更影响未来显示和统计边界；历史事件原始 UTC 时间戳不被改写。系统应提示用户该变更的影响。
- 个人界面偏好不属于家庭共享配置。家长不能因为管理角色读取成人的个人布局、搜索历史或主题偏好，除非这些数据是独立审计范围内的必要信息。
- 服务配置和 AI 配置的具体安全规则由相应模块定义，本模块仅提供受限入口、确认和审计能力。

## 5. 验收标准

| 编号         | 验收场景                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| AC-ADMIN-001 | 儿童与普通成人访问家庭管理 URL 或 API 时被拒绝；家长可查看本家庭成员但不能看到密码、令牌或成人私有健康数据。 |
| AC-ADMIN-002 | 家长撤销某成人健康共享授权后，授权状态、后续查询和工作台聚合同时生效，并产生脱敏审计事件。                   |
| AC-ADMIN-003 | 用户设置深色主题、菜单折叠和表格列偏好后刷新页面仍保留；重置偏好后业务数据不受影响。                         |
| AC-ADMIN-004 | 成员停用、服务地址变更、AI 草稿采纳和数据导出均可在授权范围内被审计查询到，事件不包含密钥或完整敏感正文。    |
| AC-ADMIN-005 | 家长导出儿童学习数据时不包含未授权成人健康数据；生成的下载链接过期后无法再访问。                             |
