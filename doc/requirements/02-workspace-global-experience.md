# 工作台与全局体验需求

## 1. 范围

本模块定义登录后应用壳、三种工作台、今日任务、全局导航、通知、搜索、布局偏好和响应式体验。前端基于 Art Design Pro 开源框架，复用快捷栏、上下文菜单、顶部工具、面包屑、标签页、卡片、趋势、表格和抽屉等基础能力；不复制商业版源码或资产。工程接入方式见[前端架构](../architecture/03-frontend-architecture.md)。

## 2. 页面与访问入口

| 页面       | 路由建议                   | 默认可见角色 | 目的                                               |
| ---------- | -------------------------- | ------------ | -------------------------------------------------- |
| 我的工作台 | `/workspace`               | 全部登录成员 | 展示当日应完成事项、进度、提醒和快捷操作。         |
| 日程与待办 | `/workspace/tasks`         | 全部登录成员 | 查看按日期聚合的任务、完成状态和来源。             |
| 通知中心   | `/workspace/notifications` | 全部登录成员 | 查看需要行动的事件与历史通知。                     |
| 全局搜索   | 模态搜索框                 | 全部登录成员 | 在有权限范围内检索导航项、计划、内容、记录和服务。 |

## 3. 功能需求

### 3.1 应用壳与导航

| ID        | 优先级 | 需求                                                                                               |
| --------- | ------ | -------------------------------------------------------------------------------------------------- |
| FR-WS-001 | P0     | 登录后系统必须展示包含一级快捷栏、上下文侧边菜单、顶部工具栏、面包屑和内容区的响应式应用壳。       |
| FR-WS-002 | P0     | 系统必须根据当前成员的后端授权返回导航项、路由与按钮能力；前端不得仅以角色名称硬编码全部可见菜单。 |
| FR-WS-003 | P0     | 当前页面必须在侧边菜单、面包屑和浏览器标题中有一致的可识别状态。                                   |
| FR-WS-004 | P0     | 用户必须能够折叠或展开上下文菜单；偏好在同一账号后续会话中恢复，但不能影响其他成员。               |
| FR-WS-005 | P1     | 用户必须能够保留有限数量的已访问内容标签页，关闭、刷新和恢复标签页不应绕过路由权限验证。           |
| FR-WS-006 | P1     | 用户必须能够开启全局专注模式。该模式隐藏非必要导航、标签页和顶栏工具，但始终保留明显的退出入口。   |
| FR-WS-007 | P1     | 用户必须能够从顶部个人菜单进入个人资料、界面偏好、当前会话和退出操作。                             |

### 3.2 角色工作台

| ID        | 优先级 | 需求                                                                                                                                        |
| --------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-WS-010 | P0     | 家长工作台必须展示本家庭的今日待完成学习、待审核项目、本周运动次数和家庭服务异常数，以及儿童学习计划、待审核队列、家庭日历和最近记录摘要。  |
| FR-WS-011 | P0     | 成人工作台必须展示本人今日学习时长、本周目标进度、今日运动、餐食记录状态、个人学习计划和健康趋势；不可展示未获授权的他人数据。              |
| FR-WS-012 | P0     | 儿童工作台必须优先展示今日学习任务、连续完成天数、课程进度和一个明确的“开始学习”操作，不展示复杂健康指标、AI 设置、服务详情或成人私有数据。 |
| FR-WS-013 | P0     | 每个指标卡必须说明其统计范围或更新时间，并能在有对应权限时跳转到明细；无数据时展示可行动的空状态而非虚构数值。                              |
| FR-WS-014 | P0     | 工作台数据必须仅由当前成员可读取的数据聚合而成；不能因为图表、计数、趋势或占位信息泄漏受限对象存在。                                        |
| FR-WS-015 | P1     | 家长可在工作台查看家庭日历中的学习和审核事项；成人和儿童只看到自己有权处理的事项。                                                          |
| FR-WS-016 | P1     | 工作台可展示最近活动时间线，但必须按对象权限过滤，并避免在儿童界面出现成人行为或敏感摘要。                                                  |

### 3.3 今日任务与日程

| ID        | 优先级 | 需求                                                                                                             |
| --------- | ------ | ---------------------------------------------------------------------------------------------------------------- |
| FR-WS-020 | P0     | 系统必须从学习计划、练习、审核任务和个人记录目标生成或聚合当日待办，并标明来源、截止日期、完成状态和可执行入口。 |
| FR-WS-021 | P0     | 用户完成可完成任务后，任务状态与关联业务记录必须一致更新；重复提交不能产生重复完成记录。                         |
| FR-WS-022 | P0     | 用户必须能区分“未开始”“进行中”“已完成”“已逾期”和“无需处理”的任务状态。                                           |
| FR-WS-023 | P1     | 家长可为儿童学习任务调整日期、取消或重新安排，并保留调整摘要。                                                   |
| FR-WS-024 | P1     | 成人可创建个人提醒；提醒不得被默认共享给家庭成员。                                                               |

### 3.4 通知与全局搜索

| ID        | 优先级 | 需求                                                                                               |
| --------- | ------ | -------------------------------------------------------------------------------------------------- |
| FR-WS-030 | P0     | 系统必须为需要行动的事件生成站内通知，例如任务到期、练习反馈、待审核 AI 草稿和已批准服务状态异常。 |
| FR-WS-031 | P0     | 用户必须能查看未读计数、将通知标记为已读，并跳转到仍有权限访问的目标对象。                         |
| FR-WS-032 | P0     | 通知标题和摘要必须按接收者权限裁剪；儿童通知不得泄漏成人健康、服务配置或家庭管理信息。             |
| FR-WS-033 | P1     | 系统必须提供快捷键或可见入口打开全局搜索。搜索结果只包含当前成员有权读取的页面和对象。             |
| FR-WS-034 | P1     | 全局搜索必须支持按对象类型筛选，并在结果中显示足以区分对象的安全摘要、最后更新时间和跳转动作。     |
| FR-WS-035 | P1     | 不存在或无权对象不能通过搜索建议、联想词、结果数量或错误信息被推断。                               |

### 3.5 视觉、响应式与状态反馈

| ID        | 优先级 | 需求                                                                                                                       |
| --------- | ------ | -------------------------------------------------------------------------------------------------------------------------- |
| FR-WS-040 | P0     | 桌面应用壳应保留图标快捷栏、约 224px 的上下文菜单、顶部工具和紧凑内容区；内容区使用稳定网格和不超过 8px 的卡片圆角。       |
| FR-WS-041 | P0     | 在窄屏下，菜单必须转换为可关闭抽屉，复杂图表转换为单列，表格提供可扫描的卡片或详情入口；文本、按钮和焦点不能重叠或被裁切。 |
| FR-WS-042 | P0     | 页面必须提供加载、空、权限不足、网络失败和服务端失败状态，并给出与当前操作对应的重试、返回或创建动作。                     |
| FR-WS-043 | P0     | 所有仅图标按钮必须具有可访问名称或工具提示；键盘焦点可见，关键操作可通过键盘完成。                                         |
| FR-WS-044 | P1     | 用户可在浅色、深色和低刺激阅读主题之间选择；主题变更必须同时影响菜单、卡片、表单、图表和状态色，而非只更换页面背景。       |
| FR-WS-045 | P1     | 图表的趋势、状态和分类不能只使用颜色表达，必须提供文字、图例或可访问摘要。                                                 |

## 4. 关键业务规则

- 工作台是聚合视图，不是新的数据源。卡片数值、趋势和待办必须可追溯到学习、健康、服务或审核模块的真实记录。
- “今天”的计算使用家庭时区；跨午夜的任务和趋势统计应采用统一的时区边界。
- 任务来源为学习计划或审核流时，应由来源对象决定可编辑性，不能在工作台创建一个脱离来源的副本。
- 刷新、全屏、主题、菜单折叠和专注模式属于界面偏好；它们不应变更业务数据或权限。
- 导航与搜索的显示层可缓存，但受权限影响的数据必须在权限、成员或家庭上下文变化时失效。

## 5. 验收标准

| 编号      | 验收场景                                                                                                                   |
| --------- | -------------------------------------------------------------------------------------------------------------------------- |
| AC-WS-001 | 家长、成人和儿童登录同一家庭后，分别看到相应的工作台卡片、导航和待办，且儿童不能通过前端路由或搜索进入管理与健康数据页面。 |
| AC-WS-002 | 成人没有健康共享授权时，家长工作台的健康相关卡片不显示该成人的数值、趋势、名称或占位计数。                                 |
| AC-WS-003 | 儿童完成今日练习后，任务状态、练习记录和学习时长刷新后一致；重复点击提交不会产生两条完成记录。                             |
| AC-WS-004 | 数据为空时，工作台显示明确的创建或开始操作；图表、指标和表格不显示模拟数据。                                               |
| AC-WS-005 | 在 768px 宽度下，导航可打开和关闭，内容无水平遮挡，表格和图表均可完成对应任务。                                            |
| AC-WS-006 | 全局搜索输入受限成员姓名或服务名时，无权用户得不到联想、结果、计数或存在性提示。                                           |
